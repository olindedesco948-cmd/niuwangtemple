# 牛王庙 - A股祈福小程序

一个轻松、卡通、带有仪式感的小程序。用户每天在 A 股开盘前或收盘后进入「牛王庙」，点击点一根香，为自己的持仓和账户心态祈福。

## 功能特点

### 1. 首页
- 卡通风格 Hero 主图（金牛、香炉、K线元素）
- 实时状态显示（是否可上香）
- 主按钮交互
- 今日祈福语展示
- 祈福记录入口

### 2. 点香交互
- 点击按钮后触发动画（烟雾上升、金牛发光）
- 本地存储每日祈福状态
- 随机展示祈福语
- 每天只能"正式上香"一次

### 3. 祈福记录
- 展示最近 7 天本地祈福记录
- 每条包含日期、时段、祈福语
- 空状态友好提示

## 祈福时间窗口

| 时段 | 时间 | 说明 |
|------|------|------|
| 早间窗口 | 09:00 - 09:30 | 开盘前祈福 |
| 收盘后窗口 | 15:00 - 22:00 | 收盘后谢市 |

> 非窗口时间允许进入页面，但主按钮显示「未到上香时辰」并展示下一个可祈福时间。

## 配置祈福时间

修改 `app.js` 中的 `incenseWindows` 配置：

```javascript
globalData: {
  incenseWindows: {
    morning: { start: '09:00', end: '09:30', label: '开盘前' },
    evening: { start: '15:00', end: '22:00', label: '收盘后' }
  }
}
```

## 添加祈福语

修改 `pages/index/index.js` 中的 `blessings` 数组：

```javascript
const blessings = [
  '愿今日心态比指数更稳',
  '愿红盘常在，回撤有度',
  // 添加更多...
]
```

## 快速开始

### 1. 微信开发者工具
1. 下载并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 新建项目，选择本项目目录
3. 填写 AppID（测试号可用测试号）

### 2. 添加主图
将 `niu-wang-miao-hero.png` 放入 `assets/images/` 目录

### 3. 预览体验
- 编译模式选择"普通编译"
- 可在不同时间窗口测试功能
