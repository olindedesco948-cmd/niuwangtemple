# 微信小程序「牛王庙」

**占位图生成工具**

---

## 使用方法

1. 在浏览器中打开 `generate-hero.html` 文件
2. 右键保存页面为 PNG，或使用截图工具截取
3. 将图片保存为 `assets/images/niu-wang-miao-hero.png`
4. 删除或重命名 `placeholder.png`

---

## 推荐的主图风格

如果您需要一张更好的主图，可以向 AI 绘图工具描述以下内容：

> 卡通风格的中式小庙建筑，庙顶为金色/朱红色调，庙前有一只金色金牛雕塑和香炉。背景是淡淡的股市K线图案作为装饰。整体色调温暖（朱红、金色、深蓝），有祈福仪式感但不过于严肃。适合作为手机壁纸比例（9:16或3:4）。

---

## 推荐尺寸

- 宽度：750px（适配 iPhone 6/7/8 宽度）
- 高度：420px - 500px
- 格式：PNG，带透明背景更佳
