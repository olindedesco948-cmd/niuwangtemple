# assets 资源目录

## 图片资源

### 主图（必需）
- `images/niu-wang-miao-hero.png` - 首页 Hero 主图
  
  **推荐规格**：宽度 750px，高度 ~420px（rpx）
  
  **推荐风格**：
  - 卡通中式小庙，带庙顶（金色/朱红色调）
  - 庙前有金牛雕塑
  - 香炉位于中央
  - 背景有淡淡的红绿K线图案（象征股市）
  - 整体温暖、卡通、有仪式感但不迷信

  **备选方案**：
  - 可使用 AI 生成的图片
  - 或使用纯 CSS/Canvas 绘制

### 占位图
- `images/placeholder.png` - 图片加载失败时的占位图
  
  **推荐规格**：宽度 750px，高度 420px
  
  **风格**：与主图背景一致，显示"牛王庙"文字即可

## 图标使用
推荐使用 emoji 作为图标：
- 🐂 金牛
- 🏺 香炉
- 🙏 祈福
- 📿 念珠
- 📜 记录
- 🔥 香火
- ⏰ 时间
- ⏳ 等待
- ✨ 完成
- 🏛️ 空状态寺庙

如需更精细的图标，可使用 iconfont 或自绘 SVG。
